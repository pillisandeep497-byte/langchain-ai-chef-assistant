# 🍳 LangChain AI Chef Assistant

An AI-powered cooking assistant built using:

- LangChain
- Google Gemini
- Pydantic Output Parser
- Chat Memory
- Python

## Features

✅ Recipe generation

✅ Structured output

✅ Conversation memory

✅ Detailed ingredients

✅ Cooking precautions

✅ Step-by-step cooking process

✅ Optional cooking tips
